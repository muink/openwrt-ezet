Config server for easytier. easytier-core gets config from this and web frontend use it as restful api server.

Usage: easytier-web [OPTIONS]

Options:
  -d, --db <DB>
          path to the sqlite3 database file, used to save all the data [env: ET_WEB_DB=] [default: et.db]
      --console-log-level <CONSOLE_LOG_LEVEL>
          The log level for the console logger. Possible values: trace, debug, info, warn, error [env:
          ET_WEB_CONSOLE_LOG_LEVEL=]
      --file-log-level <FILE_LOG_LEVEL>
          The log level for the file logger. Possible values: trace, debug, info, warn, error [env:
          ET_WEB_FILE_LOG_LEVEL=]
      --file-log-dir <FILE_LOG_DIR>
          The directory to save the log files, default is the current directory [env: ET_WEB_FILE_LOG_DIR=]
  -c, --config-server-port <CONFIG_SERVER_PORT>
          The port to listen for the config server, used by the easytier-core to connect to [env:
          ET_CONFIG_SERVER_PORT=] [default: 22020]
  -p, --config-server-protocol <CONFIG_SERVER_PROTOCOL>
          The protocol to listen for the config server, used by the easytier-core to connect to, possible values: udp,
          tcp, ws [env: ET_CONFIG_SERVER_PROTOCOL=] [default: udp]
  -a, --api-server-port <API_SERVER_PORT>
          The port to listen for the restful server, acting as ApiHost and used by the web frontend [env:
          ET_API_SERVER_PORT=] [default: 11211]
      --api-server-addr <API_SERVER_ADDR>
          The listen address for the restful server, e.g. 0.0.0.0, ::, 127.0.0.1 [env: ET_API_SERVER_ADDR=] [default:
          0.0.0.0]
      --geoip-db <GEOIP_DB>
          The path to the GeoIP2 database file, used to lookup the location of the client, default is the embedded file
          (only country information) , recommend https://github.com/P3TERX/GeoLite.mmdb [env: ET_GEOIP_DB=]
      --heartbeat-min-response-ms <HEARTBEAT_MIN_RESPONSE_MS>
          Config-server heartbeat interval in milliseconds, default is 3500 [env: ET_HEARTBEAT_MIN_RESPONSE_MS=]
          [default: 3500]
      --heartbeat-timeout-ms <HEARTBEAT_TIMEOUT_MS>
          Config-server heartbeat RPC timeout in milliseconds, default is 15000 [env: ET_HEARTBEAT_TIMEOUT_MS=]
          [default: 15000]
      --gateway-peer-url <GATEWAY_PEER_URL>
          [env: ET_GATEWAY_PEER_URL=]
      --gateway-relay-data
          [env: ET_GATEWAY_RELAY_DATA=]
  -l, --web-server-port <WEB_SERVER_PORT>
          The port to listen for the web dashboard server, default is same as the api server port [env:
          ET_WEB_SERVER_PORT=]
      --web-server-addr <WEB_SERVER_ADDR>
          The listen address for the web dashboard server (only effective when web_server_port differs from
          api_server_port or web_server_addr differs from api_server_addr), e.g. 0.0.0.0, ::, 127.0.0.1 [env:
          ET_WEB_SERVER_ADDR=] [default: 0.0.0.0]
      --no-web
          Do not run the web dashboard server [env: ET_NO_WEB=]
      --api-host <API_HOST>
          The URL of the API server, used by the web frontend to connect to [env: ET_API_HOST=]
      --disable-registration
          Disable user registration [env: ET_DISABLE_REGISTRATION=]
      --allow-auto-create-user
          Allow auto-creating local user when easytier-core connects with an unknown username [env:
          ET_ALLOW_AUTO_CREATE_USER=]
      --oidc-issuer-url <OIDC_ISSUER_URL>
          The OIDC issuer URL for single sign-on authentication
      --oidc-client-id <OIDC_CLIENT_ID>
          The OIDC client ID
      --oidc-client-secret <OIDC_CLIENT_SECRET>
          The OIDC client secret (can also be set via OIDC_CLIENT_SECRET env var) [env: OIDC_CLIENT_SECRET=]
      --oidc-username-claim <OIDC_USERNAME_CLAIM>
          The OIDC claim to use as the local username, default: preferred_username [default: preferred_username]
      --oidc-scopes <OIDC_SCOPES>
          OIDC scopes to request during login. Supports comma-separated values or repeated --oidc-scopes flags, default:
          openid,profile [default: openid profile]
      --oidc-redirect-url <OIDC_REDIRECT_URL>
          The OIDC redirect URL (callback URL), must match exactly what is registered with your Identity Provider.
          Required when using OIDC. Example: http://your-domain.com:11211/api/v1/auth/oidc/callback
      --oidc-disable-pkce
          Disable PKCE (Proof Key for Code Exchange) for OIDC authentication
      --oidc-frontend-base-url <OIDC_FRONTEND_BASE_URL>
          Frontend base URL to redirect to after successful OIDC callback. Required when frontend and API are deployed
          separately (non-embed build, --no-web mode, or different web_server_port)
      --webhook-url <WEBHOOK_URL>
          Base URL of the webhook endpoint for token validation and event delivery. When set, incoming tokens are
          validated via this webhook before local fallback [env: ET_WEBHOOK_URL=]
      --webhook-secret <WEBHOOK_SECRET>
          Shared secret used to authenticate outbound webhook calls [env: ET_WEBHOOK_SECRET]
      --internal-auth-token <INTERNAL_AUTH_TOKEN>
          Token for X-Internal-Auth header. When set, API requests with this header bypass session authentication [env:
          ET_INTERNAL_AUTH_TOKEN]
      --web-instance-id <WEB_INSTANCE_ID>
          Stable identifier for this easytier-web instance when routing webhook callbacks [env: ET_WEB_INSTANCE_ID=]
      --web-instance-api-base-url <WEB_INSTANCE_API_BASE_URL>
          Reachable base URL for this easytier-web instance's internal REST API [env: ET_WEB_INSTANCE_API_BASE_URL=]
  -h, --help
          Print help
  -V, --version
          Print version
