manage vpn portal (wireguard) clients

Usage: easytier-cli vpn-portal [COMMAND]

Commands:
  add-client     Add a WireGuard portal client
  remove-client  Remove a WireGuard portal client
  clear-clients  Remove all WireGuard portal clients
  help           Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
